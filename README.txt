SHANICE'S KPSEA CONGRATULATIONS WEBSITE

Files:
- index.html  (website content)
- style.css   (design and animations)
- script.js   (name check and surprise reveal)

PUBLISH WITH GITHUB PAGES:
1. Sign in to GitHub and create a new repository. You can call it shanice-surprise.
2. Upload index.html, style.css and script.js to the repository's main/root folder.
3. Open the repository's Settings.
4. Select Pages from the left menu.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub to publish the site. The Pages address will appear in Settings > Pages.

NOTE:
The name check is a fun surprise, not real security. Because GitHub Pages hosts static files, the name check happens in the visitor's browser.
